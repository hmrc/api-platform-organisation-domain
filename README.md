
# API Platform Organisation Domain

This is where the domain objects and test fixtures are kept for the API platform
organisations structure

### Country list

This repo contains the list of countries accepted for international addresses, derived from the
[FCDO Geographical Names Index](https://www.data.gov.uk/dataset/0b412b57-6934-4f28-b495-640cdc7e8f7f/foreign-commonwealth-and-development-office-geographical-names-index)
(July 2026 CSV).
